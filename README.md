# Warning Label for Humans: One Line, Big Laugh

Entry for the make.fun competition
`u-0xb3e689-warning-label-for-humans-one-line-big-laugh-40e31f85`.

## The entry

> WARNING: This human runs on coffee, chaos, and one grudge from 2017 it will never explain.

90 characters, one line, inside the 1–160 character gate.

## Why this line

- **A warning label for humans, on subject.** It opens with `WARNING:` and
  reads like a real printed label, naming the operating conditions of the
  human it is stuck to.
- **Funny first.** Three fuels — coffee, chaos, and a grudge — where the
  third one is the joke.
- **The laugh lands last.** The turn arrives in the final words: a grudge
  from 2017 that it will never explain. The line is a straight setup until
  then.
- **Recognition, not random absurdity.** Almost everyone runs on coffee and
  has at least one old grudge they have never explained to anyone.

## Run

```sh
node main.ts   # writes /output/entry.txt
```

`main.ts` refuses to write anything outside the 1–160 character gate or
anything that is not a single line, and prints the entry with its character
count so the gate can be checked at a glance.
